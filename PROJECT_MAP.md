> **MANDATORY FOR EVERY NEW CHAT:** This map is the standard project structure.
> - Every new feature, file, or directory MUST be placed according to this map
> - If any file/directory is added, moved, renamed, or removed, you MUST update this map in the same commit/session
> - New chats MUST read this file together with `Master Code Rules.md`, `AGENTS.md`, and `X5_AGENT_PROTECTION_PLAN.md` before any coding

## Embedding Auto-Logic
- On startup (`main.py` + `tool_search` first call) -> `plugins/tool-discovery/search/store.py:ensure_embeddings()`:
  - collects all discoverable specs (verbatim descriptions: the core_plugins specs + workspace + document_search + the 36 browser tools = 57 total; image_memory/important_memory removed, memory added)
  - computes SHA256 hash
  - if hash matches the stored hash in the Chroma `tools` collection (collection metadata) -> reuse
  - else if the collection is empty and the shipped `storage/vector/tool_embeddings.seed.json` hash matches (or a legacy `tool_embeddings.json` exists) -> import it into Chroma instantly (zero model calls, fully offline)
  - else INCREMENTAL update: every entry carries a per-spec fingerprint — stored vectors with a matching fingerprint are reused as-is, only new/changed specs are embedded via `core/embedding/service.py` (bundled embedding model, 3 retries), then the collection is rewritten with the new hash (dimension guard re-embeds on model swap, never mixes dims; a file-based single-flight guard serializes concurrent rebuilds across threads/processes)
- If user edits any description in spec.json and reruns code, change is detected automatically and only that spec is re-embedded (legacy fingerprint-less stores are stamped once without re-embedding).
- Every user message + assistant reply is embedded automatically on persist (`core/agent/loop/engine.py:_persist_conversation` -> `chat_vector_store.add_message`).
- Device (GPU/CPU) is detected once at startup and cached (`core/embedding/bootstrap.py:detect_device`).
- Rebuild seeds after spec changes: `python scripts/build_embedding_seed.py` (or `--snapshot-only` when the runtime store is fresh).
